# Contributing to Awesome Agent Trading Skills

Thank you for your contribution! This list focuses on **installable trading skills/plugins for AI agents**.

## What Qualifies

- ✅ Skills that let agents **trade** (execute orders, manage positions)
- ✅ Skills that provide **market data** for trading decisions
- ✅ Skills for **risk management** and position sizing
- ✅ Skills for **any agent platform** (OpenClaw, ElizaOS, etc.)
- ✅ Verified skills from ClawHub, GitHub, or other registries

## What Doesn't Qualify

- ❌ General agent frameworks (those go in [awesome-agent-trading](https://github.com/laplace0x/awesome-agent-trading))
- ❌ Raw APIs or SDKs without an agent skill wrapper
- ❌ Closed-source / paid-only tools with no free tier

## How to Add

1. Fork this repo
2. Add your entry to the appropriate section in README.md
3. Use the existing table format: `| Skill | Author | Description | Install |`
4. Submit a PR

## Format

```
| [Skill Name](link) | Author | Brief description | `openclaw skills add author/skill` |
```

## Safety Note

If a skill has known security issues, please note them. We want this list to help traders find **safe** skills.

Thank you! 🙏
